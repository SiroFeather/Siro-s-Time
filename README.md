# 时停（Time Stop）— Forge 1.20.1

一个"时停（The World 式）"模组：手持时停怀表右键，**整个世界除你之外的时间停止**——怪物/动物/其他玩家的运动、AI、判定全部冻结；再次右键解除。解除后的短暂窗口内移除原版受伤无敌帧，便于打出连击。

- Minecraft：**1.20.1**
- Forge：**47.x**（开发基于 `1.20.1-47.2.0`）
- 模组 ID：`timestop`
- 版本：**1.3.0**
- Java：**17**

---

## 一、功能一览

| 功能 | 说明 |
| --- | --- |
| 时停物品「时停怀表」 | 手持右键**开启**时停，再次右键**解除**；创造标签页可获取 |
| 新物品「时间瓶」 | 无效果，仅作为时停怀表的**合成材料**：手持玻璃瓶（主/副手）连续 10 分钟充能获得 |
| 时停怀表合成 | 3×3：金锭围十字、中心放时间瓶（` g / gBg / g `，g=金锭，B=时间瓶） |
| 全实体冻结 | 除"使用者本人"外所有实体的运动、事件、判定、AI 全部停止（生物取消 tick + 非生物快照复位） |
| 多人安全 | 时停中其他玩家无法移动、使用物品、攻击、交互；状态/白名单/豁免经网络包同步，多人表现一致 |
| 无敌帧移除窗口 | **整个时停期间 + 解除后 0.5 秒**内，每 tick 清零 `invulnerableTime/hurtTime`，连续攻击每次满额伤害 |
| 客户端动画冻结 | 生物停在当前姿势（走路摆动/挥臂/使用物品动画冻结）；非生物实体（物品旋转、船/矿车摆动）快照复位 + 冻结 tickCount |
| 时停滤镜 | 时停期间叠加半透明金色滤镜，模拟 "The World" 氛围 |
| 音效/粒子 | 开启播放 DIO 语音，解除播放提示音；开启/解除有金色/传送门粒子爆发 |
| 白名单 | 可配置不被冻结的实体（支持 `modid:*` 通配） |

## 二、模组兼容（软依赖，未安装不影响本模组）

| 模组 | 适配内容 |
| --- | --- |
| **车万女仆**（Touhou Little Maid） | 女仆实体默认进入白名单，时停中可继续执行任务；`maidFollowDuringTimeStop` 可让女仆在时停中跟随主人 |
| **TACZ**（Timeless and Classics: Zero） | 时停中可开枪，**子弹定在空中**；时停解除后恢复子弹速度，**续飞并造成伤害** |
| **拔刀剑**（SlashBlade Resharped） | 时停中**豁免停时者本人发射的召唤剑/斩击投射物**，可正常命中造成伤害；并修复 1.20.1 `hurt()` 的 `lastHurt` 门导致的"连招后续段被挡"问题 |
| **FTB Teams** | 时停时**自动豁免与时停者同队伍的玩家及其仆从/被驯服实体**（服务端 + 客户端同步） |

> 说明：本模组通过 `ModList` 检测与实体注册名/反射识别外部模组实体，**绝不直接引用对方类**，未安装时无硬崩溃。

## 三、使用

1. 创造标签页取「时停怀表」，或用命令 `/give @p timestop:time_stop_item`。
2. 手持时停怀表**右键** → 时停开始（金色滤镜 + 语音 + 粒子爆发）。
3. 世界定格，只有你能移动/攻击；再次右键 → 时停解除。
4. 解除后 0.5 秒内没有受伤无敌帧，可连续追击。

## 四、配置

配置文件：`config/timestop-server.toml`

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `whitelist` | `["touhou_little_maid:maid"]` | 时停时不被冻结的实体注册名，支持精确 ID 与 `modid:*` 通配 |
| `invulnWindowTicks` | `10` | 无敌帧移除窗口长度（tick，20=1 秒）。整个时停期间生效，并在解除后再延续该时长 |
| `maidFollowDuringTimeStop` | `false` | 车万女仆在时停中是否保持跟随 AI |
| `resumeProjectilesOnRelease` | `true` | 时停解除时恢复被冻结实体的速度（子弹/箭矢/掉落物续飞） |
| `ftbTeamFreezeExemption` | `true` | FTB Teams：时停时豁免同队玩家与仆从 |

## 五、从源码构建

环境要求：JDK 17、Gradle（项目自带 wrapper）。

```bash
git clone https://github.com/SiroFeather/Siro-s-Time.git
cd Siro-s-Time
./gradlew build
```

产物：`build/libs/timestop-1.3.0.jar`，放入游戏 `mods/` 目录即可。
